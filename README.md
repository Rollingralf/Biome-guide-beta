# 🌍 Minecraft Biome Guide

Een volledige Electron desktop applicatie die alles uitlegt over Minecraft Biomes, hun eigenschappen, items en resources.

## ✨ Features

- 📚 Gedetailleerde informatie over 10+ Minecraft biomes
- 🔍 Zoekfunctie om snel biomes te vinden
- 📦 Volledige list van items en resources per biome
- 🎨 Moderne, gebruiksvriendelijke interface
- 🌍 Responsive design
- 🚀 Kant-en-klaar desktop app

## 🚀 Quick Start

### Installatie

1. **Node.js en npm installeren** (als je dit nog niet hebt)
   - Download van: https://nodejs.org/

2. **Repository klonen en dependencies installeren**
   ```bash
   cd Biome-guide-beta
   npm install
   ```

3. **App starten**
   ```bash
   npm start
   ```

## 🛠️ Beschikbare commando's

```bash
# App starten (ontwikkeling)
npm start

# App bouwen als installatiebestand (Windows)
npm run build-win

# App bouwen als DMG (macOS)
npm run build-mac

# App bouwen als AppImage (Linux)
npm run build-linux

# Alle platforms bouwen
npm run build
```

## 📦 Gedownloade App Gebruiken

Zodra de app is gebouwd, vind je het installatiebestand in de `dist/` map:

### Windows
- `Minecraft Biome Guide Setup 1.0.0.exe` - Gewone installer
- `Minecraft Biome Guide 1.0.0.exe` - Draagbare versie

### macOS
- `Minecraft Biome Guide-1.0.0.dmg` - DMG installer
- `Minecraft Biome Guide-1.0.0.zip` - ZIP archive

### Linux
- `minecraft-biome-guide-1.0.0.AppImage` - AppImage bestand
- `minecraft-biome-guide_1.0.0_amd64.deb` - DEB package

Eenvoudig downloaden, installeren en gebruiken!
