# ⚡ Quick Start - Minecraft Biome Guide

## Voor Ontwikkelaars (npm vereist)

```bash
# 1. Dependencies installeren (eerste keer)
npm install

# 2. App in dev mode starten
npm start
```

## Voor Eindgebruikers (gewone mensen)

### Methode 1: Download de .EXE (MAKKELIJKST)
1. Download `Minecraft Biome Guide Setup 1.0.0.exe` van releases
2. Dubbelklik erop
3. Volg de installatie wizard
4. Klaar! 🎉

### Methode 2: Draagbare versie (geen installatie)
1. Download `Minecraft Biome Guide-1.0.0-Portable.exe`
2. Dubbelklik erop
3. Klaar! Geen installatie nodig!

---

## Voor Ontwikkelaars: Een Nieuwe .EXE Maken

Waneer je wijzigingen hebt gemaakt en wilt bouwen:

```bash
# Bouw Windows installer
npm run build-win

# De EXE files zijn nu in: dist/
```
